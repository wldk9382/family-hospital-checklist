# 가족 공동 임시 체크리스트

Node.js 20 이상 필요. 외부 패키지, 로그인, 계정, 쿠키, 추적 도구 없음.

```bash
node server.js
```

http://localhost:3000 에 접속하면 임의의 144비트 비밀 링크가 생성됩니다. 링크를 공유하면 가족들이 같은 체크 상태를 볼 수 있습니다. 변경 사항은 Server-Sent Events(SSE)로 즉시 전파됩니다. 데이터는 서버의 `rooms.json`에 저장되며 **방 생성 시점부터 24시간 후** 만료·삭제됩니다. 서버 재시작 후에도 유효기간 내 기록은 유지됩니다. 만료 데이터는 서버 요청 시 또는 30초 간격으로 정리됩니다.

## 인터넷 공개 배포

이 프로젝트는 **지속적인 파일 저장이 가능한 Node.js 호스팅**에 올려야 합니다. 예: 개인 VPS, 영구 디스크가 연결된 Node 서버. Vercel 서버리스 환경에 그대로 올리면 파일 영속성과 SSE가 보장되지 않으므로 사용하지 마세요. HTTPS를 적용하고, 가족에게 URL을 카카오톡으로 공유하세요.

링크 자체가 접근 권한입니다. 링크를 받은 누구나 체크를 수정할 수 있으므로 공개 게시하지 마세요. 의료 기록, 실명, 주민등록번호 등 민감정보는 입력하지 마세요. 24시간 후 삭제는 앱의 저장 데이터에 적용되며 호스팅 사업자의 로그나 외부 백업까지 삭제한다는 뜻은 아닙니다.
